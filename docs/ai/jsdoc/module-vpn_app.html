Module: vpn_app

Browser application wiring for the wg_manager VPN frontend. Coordinates login, authenticated session lifetime, peer CRUD, provisioning, local X25519 WireGuard key generation, config/QR export and admin account/ ownership operations. Private keys exist only in browser memory and rendered configuration until the user exports or discards them.
